## Überblick

VBScript ist eine Skriptsprache für Windows, die in verschiedenen Bereichen eingesetzt werden kann. Sie ist leicht zu erlernen und dient als Einstieg in Visual Basic für Windows, von dem sie direkt abgeleitet ist.

Obwohl VBScript keine objektorientierte Sprache ist (das Konzept der Vererbung existiert beispielsweise nicht), weist sie einige objektorientierte Merkmale auf. Ihre Stärke liegt in der Fähigkeit, die vom jeweiligen Ausführungscontainer bereitgestellten Objekte sowie die auf dem Windows-Computer verfügbaren ActiveX-Komponenten zu nutzen. Dadurch kann sie mit Sprachen konkurrieren, die ursprünglich über einen größeren Funktionsumfang verfügten, wie Perl, JavaScript oder Python.

## Ausführungsumgebungen

VBScript kann in verschiedenen Umgebungen ausgeführt werden:

**Windows Scripting Host (WSH)**: Für den direkten Einsatz unter Windows, insbesondere zum Schreiben von Skripten zur Systemadministration. WSH ist in der Regel standardmäßig im Windows-Betriebssystem enthalten.





**Internet Explorer**: Wird innerhalb von HTML-Seiten verwendet und bietet eine Interaktivität, die mit HTML allein nicht erreicht werden kann.


**Internet Information Server (IIS) / Personal Web Server (PWS)**: VBScript wird für die serverseitige Webprogrammierung über die ASP-Technologie (Active Server Pages) von Microsoft verwendet.





## Verbindung zu Visual Basic und VBA

Da VBScript von Visual Basic abgeleitet ist, dient es als hervorragende Einführung in diese im Windows-Ökosystem weit verbreitete Sprache. Darüber hinaus bereitet es Benutzer auf **VBA (Visual Basic for Applications)** vor, die in der Microsoft Office-Suite (insbesondere Excel) verwendete Version.

Daher ist VBScript ein idealer Einstiegspunkt für die Entwicklung von Windows-Anwendungen.
